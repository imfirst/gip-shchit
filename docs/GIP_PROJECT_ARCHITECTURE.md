# ГИП — автоматическое проектирование квартир: архитектура

## Что есть
- **Плагин** (`plugin/GipShchit`, C#, .NET Framework 4.8, AutoCAD 2021–2024): палитры PaletteSet + WebView2.
  - `PanelControl` — «Группы щита» (GIPPANEL), `RoomsControl` — «Помещения» (GIPROOMS), `HeatControl` — «Отопление» (GIPHEAT);
  - `SystemControl` — общая панель системы по описанию `SystemSpec` (страница, файлы обмена, белый список команд):
    «Кондиционирование» и «Проект»;
  - `ProjectHost` — единая палитра **«ГИП · Проект» (GIPPROEKT)** с вкладками всех панелей.
- **Страницы** (`web/src/*`, собираются `web/build.py` в `dist/*.html`): расчёт и подбор — в JS, без сервера.
- **AutoLISP** (`lisp/src/*.lsp` → `dist/GIP_SHCHIT.lsp`): построение графики в чертеже.
- **Эмулятор** (`lisp/emu`): AutoLISP + модель AutoCAD на DXF шаблона; тесты построения на реальном шаблоне.
- **Шаблон** `template/GIP_VIK_EOM_O_Shablon.dxf`: ВиК + ЭОМ + альбом О (собирается `tools/heat_template.py`).

## Обмен данными
Панель → AutoCAD: строка `тип\nтело` (`ready`, `build` / `heat` / `apply`, `cmd` — команда из белого списка, `tab`).
Данные построения — ASCII-файл во временной папке (`gip_<система>_in.txt`, формы LISP, не-ASCII как `~uXXXX`).
AutoCAD → панель: итог `gip_<система>_out.txt` и реестр `gip_<система>_reg.txt` (JSON); реестр пишет каждая команда,
по нему панель понимает, что команда закончилась.

Состояние хранится в чертеже (словарь именованных объектов, XRecord): `GIPROOMS` (реестр помещений — единственный
источник помещений для всех систем), `GIPPANEL`, `GIPHEAT*`, `GIPCOND*` (точки блоков, состояние панели, длины),
`GIPPROEKT` (данные проекта), `GIPRTWALL` (слои стен своей подложки).

## Графика
Всё созданное помечено xdata приложения системы (`GIPHEAT`, `GIPCOND`, …) с видом объекта; перестроение стирает
только своё в рамках своих листов. Листы находятся по рамкам `А3-GIP-ALBOM/BOOK` и названию в штампе.
Трассировка — общее ядро (`77_routes.lsp`: сетка стен, помещения, Дейкстра; `78_heat.lsp`: лучевые пары от источника,
ортогонально в системе стен). Кондиционирование использует ядро отопления: пара Х1/Х2 = пара Т1/Т2 с шагом 50,
дерево VRF и дренаж — «лучи» с нулевым шагом, совпадающие участки прорежаются (рефнеты/тройники в точках отхода).

## Этапы
1. ✔ Аудит, документ (этот файл).
2. ✔ Панель проекта GIPPROEKT: данные проекта в чертеже, состояние систем, проверка комплекта, вкладки систем.
3. ✔ Геометрия: подложка из PDF (GIPROOMS) или своя (GIPWALLS); окна, точки оборудования.
4. ВК — водоснабжение и канализация: впереди (база приборов, коллекторы/тройники, уклоны, схемы).
5. ✔ ЭОМ (щит, однолинейная, монтажная, спецификация, трассы силовых) — существующий ГИП-ЩИТ.
6. ✔ Отопление (GIPHEAT). ✔ Кондиционирование (GIPCOND).
7. Дальше: общие отметки и проверка пересечений систем, заполнение штампов из данных проекта, PDF комплекта.
