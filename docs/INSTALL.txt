GIP-ЩИТ для AutoCAD 2021–2024 — установка

1. Закройте AutoCAD.

2. Скачанный архив GIP_SHCHIT_AutoCAD.zip: правой кнопкой → «Свойства» → внизу отметьте «Разблокировать» → ОК.
   Без этого Windows не даст AutoCAD загрузить DLL, скачанную из интернета.

3. Распакуйте папку GIP.bundle в
      %APPDATA%\Autodesk\ApplicationPlugins
   (вставьте эту строку в адресную строку Проводника; если папки ApplicationPlugins нет — создайте её).
   Должно получиться: ...\ApplicationPlugins\GIP.bundle\PackageContents.xml
   Если раньше вы добавляли GIP_SHCHIT.lsp в «Автозагрузку» (ЗАГПРИЛ / APPLOAD) — уберите его оттуда:
   теперь программа загружается из GIP.bundle сама.

4. Запустите AutoCAD. Если он спросит про безопасность — «Всегда загружать».

5. Откройте чертёж из шаблона GIP_EOM_Shablon (архив GIP_EOM_Shablon.zip лежит там же, в Releases)
   и наберите ГИППАНЕЛЬ (или GIPPANEL). Откроется панель «Группы щита» — её можно закрепить у края экрана.

КАК РАБОТАТЬ
- В чертеже ещё нет щита: «Собрать по шаблону» → выберите квартиру → «Собрать щит» → «Построить альбом в этом чертеже».
- Дальше любая правка в таблице (перенос строк, назначение, защита, номинал, фаза, кабель…) сразу перестраивает
  однолинейку, монтажную схему и спецификацию. Галочка «Сразу в чертёж» вверху: если её снять, чертёж обновляется
  кнопкой «Обновить чертёж».
- Аппараты на монтажной схеме можно по-прежнему двигать мышью — таблица подхватит новый порядок и удалённые аппараты.
- Ctrl+Z в таблице отменяет правку таблицы (чертёж перестроится обратно); Ctrl+Z в AutoCAD отменяет последнее
  перестроение — таблица тоже вернётся.
- Чертёж, собранный раньше командой ГИПЩИТ, панель подхватит сама. ГИПЩИТ по-прежнему работает: кнопка ОК в его окне
  собирает щит заново по шаблону.

ЕСЛИ ЧТО-ТО НЕ ТАК
- Панель пишет «Не удалось открыть панель… WebView2» — установите Microsoft Edge WebView2 Runtime (Evergreen)
  с сайта Microsoft и перезапустите AutoCAD.
- Команда GIPPANEL неизвестна — проверьте путь ...\ApplicationPlugins\GIP.bundle\PackageContents.xml и что архив
  был разблокирован до распаковки.
- Ошибки панели записываются в %LOCALAPPDATA%\GIP\panel.log; в самой панели клавиша F12 открывает консоль.
  Пришлите этот текст или текст из командной строки AutoCAD («GIP-ЩИТ: ошибка — …») — исправлю.
- Нужен полный AutoCAD 2021–2024 (в LT не работает). Для AutoCAD 2025 и новее понадобится отдельная сборка.
